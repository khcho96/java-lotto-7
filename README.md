# 🎯 기능 구현 목록

>목록 내용이 추가 또는 수정될 수 있다.

## 1. 로또 구입 금액을 입력받는다.
- 사용자에게 로또 구입 금액 입력 메시지를 출력한다.
- 사용자로부터 로또 구입 금액을 입력받는다.
- 예외 사항
  - 공백이면 예외를 발생시킨다.
  - 숫자가 아니면 예외를 발생시킨다.
  - 1,000원 단위가 아니면 예외를 발생시킨다.
  - 100,000원을 초과하면 예외를 발생시킨다.
- 구입 금액을 정수로 변환한다.

## 2. 구입 금액에 맞는 로또를 발행한다.
- 구입 금액에 맞는 로또를 발행한다.

## 3. 발행한 로또를 출력한다.
- 발행한 로또를 오름차순으로 정렬 후 출력한다.

## 4. 당첨 번호를 입력받고 등록한다.
- 사용자에게 당첨 번호 입력 메시지를 출력한다.
- 사용자로부터 당첨 번호를 입력받는다.
- 예외 사항
  - 공백이면 예외를 발생시킨다.
  - 쉼표로 구분된 정수 입력 형식이 아니면 예외를 발생시킨다.
  - 쉼표로 구분된 값이 정수가 아니면 예외를 발생시킨다.
  - 정수의 개수가 6이 아니면 예외를 발생시킨다.
  - 1 이상 45 이하의 정수가 아니면 예외를 발생시킨다.
  - 중복된 번호가 있으면 예외를 발생시킨다.
- 당첨 번호를 등록한다.

## 5. 보너스 번호를 입력받고 등록한다.
- 사용자에게 보너스 번호 입력 메시지를 출력한다.
- 사용자로부터 보너스 번호를 입력받는다.
- 예외 사항
  - 공백이면 예외를 발생시킨다.
  - 숫자가 아니면 예외를 발생시킨다.
  - 1 이상 45 이하의 정수가 아니면 예외를 발생시킨다.
  - 당첨 번호와 중복되는 숫자면 예외를 발생시킨다.
- 보너스 번호를 등록한다.

## 6. 당첨 통계를 계산한다.
- 당첨 결과를 계산한다.
- 수익률을 계산한다.
- 결과를 반환한다.

## 7. 당첨 통계를 출력한다.
- 당첨 통계를 출력한다.
- 상금과 수익률은 세자리씩 쉼표로 끊어서 출력한다.
