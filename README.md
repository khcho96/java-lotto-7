# 기능 구현 목록

>목록 내용이 추가 또는 수정될 수 있다.

>스스로 판단한 내용은 (`판단`)이라고 표시

## 1. 로또 구입금액을 입력받는다.
  - [ ] 숫자가 아닐 시 예외 처리
  - [ ] 양수가 아닐 시 예외 처리
  - [ ] 1000원 단위가 아닐 시 예외 처리
  - [ ] 입력값의 양쪽은 공백 처리(`판단`)

## 2. 구입금액만큼의 로또를 발행한다.
  - [ ] 랜덤 메서드로 로또 번호 발행
  - [ ] 로또 번호에 중복이 있으면 예외 처리
  - [ ] 총 6개가 아닌 경우 예외처리

## 3. 발행한 로또 번호를 출력한다.

## 4. 당첨 번호 입력
  - [ ] 입력값의 양쪽은 공백 처리(`판단`)
  - [ ] 쉼표(,)로 구분
  - [ ] 쉼표로 구분한 값의 양쪽 공백 처리(`판단`)
  - [ ] 구분한 값이 숫자가 아닐 시 예외 처리
  - [ ] 범위가 1~45가 아닐 시 예외 처리
  - [ ] 구분한 값 중 중복이 있으면 예외처리(`판단`)
  - [ ] 구분한 값이 총 6개가 아니면 예외처리(`판단`)

## 5. 보너스 번호 입력
  - [ ] 입력값의 양쪽 공백 처리(`판단`)
  - [ ] 숫자가 아닐 시 예외 처리
  - [ ] 범위가 1~45가 아닐 시 예외 처리
  - [ ] 당첨 번호와 중복이면 예외 처리(`판단`)

## 6. 당첨 통계 출력
  - [ ] 당첨 등수에 대한 정보(일치하는 숫자의 개수, 상금) Enum으로 저장
  - [ ] 당첨 정보(몇 등이 몇 개인지)는 TreeMap으로 저장
  - [ ] 수익률 계산 후 출력
